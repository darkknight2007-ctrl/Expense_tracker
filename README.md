A simple, lightweight expense tracker built with Flask and SQLite.

Features:-
- Add, edit, and delete expenses (amount, category, date, note)
- Filter expenses by category and month
- Running total of all tracked expenses
- Visual breakdown with monthly spend (bar chart) and category split (pie chart)
- Export filtered expenses as CSV
- Optional per-category monthly budget limits with over-budget flagging

Tech Stack:-
- **Backend:** Flask (Python)
- **Database:** SQLite
- **Templates:** Jinja2
- **Charts:** Chart.js (via CDN)
- **Styling:** Plain CSS
